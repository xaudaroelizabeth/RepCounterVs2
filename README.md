# 💪 Rep Counter

A simple and interactive rep counter application built with JavaScript and Vite that helps users keep track of exercise repetitions during workouts in real time through a clean and easy-to-use interface.

## ✨ Features

* Track exercise repetitions in real time
* Increment rep count with a single click
* Simple and intuitive user interface
* Fast and responsive interactions

## 🛠️ Built With

* HTML
* CSS
* JavaScript
* Vite

## 🚀 Getting Started

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Once the server is running, open your browser and navigate to:

```text
http://localhost:5173
```

## 📦 Build for Production

```bash
npm run build
```

## 🔢 Counter Features

Users can:

* Increase their rep count during a workout

## 🧠 Technical Notes

💡 **State Management**

The application updates the rep count dynamically using JavaScript, allowing users to track repetitions instantly without page refreshes. Counter values are managed through event-driven interactions for a smooth user experience.
